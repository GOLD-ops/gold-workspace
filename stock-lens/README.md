# 智能选股 · GOLD Workspace

将模糊意图转成可检查、修改、执行的条件。研究用途，不提供买卖建议、确定性预测或收益承诺。

网页：https://stock-lens-lab.jincn7.chatgpt.site （私有演示，当前仅所有者可访问；公开访问须另行开放）。

源码：https://github.com/GOLD-ops/gold-workspace/tree/codex/stock-lens/stock-lens （公开源码，独立分支和目录）；Sites 源仓库用于部署同步。本目录包含完整可运行源码。

## 启动与验证

需要 Node.js 22+，无第三方依赖。在本目录执行：

```powershell
Copy-Item .env.example .env
# 本地编辑 .env，填入自己的密钥
npm run dev
```

访问 http://localhost:5180 。无密钥也可使用公开真实数据基线和明确标注的本地规则解析；过期数据进入待核验。

环境变量：AI_API_KEY、AI_BASE_URL（默认 https://api.deepseek.com）、AI_MODEL（deepseek-flash）、FUYAO_API_KEY、IFIND_AUTH_TOKEN、PORT。.env 被忽略，配置接口只返回是否已配置。线上通过秘密变量配置密钥，不嵌入网页或构建产物。

```powershell
npm test
npm run build
npm run validate
npm run collect
```

collect 有扶摇授权时写入被忽略的 data/fuyao-private.json，无授权时写入公开 data/snapshot.json；SNAPSHOT_OUTPUT 可覆盖路径。构建拒绝将扶摇授权原始数据嵌入源码。worker/index.js 为自动生成的独立 Worker，dist 为部署产物。

## 主链路

1. 首页以一句话输入为主入口，点击“整理筛选条件”；此时不显示候选名单。
2. 检查白话条件，指标右侧问号支持悬停、键盘聚焦和手机点击。高级编辑与澄清选项折叠；冲突或未处理的不支持要求禁止执行。点击“按这些条件筛选”即确认本次条件，无额外确认勾选。
3. 查看符合、未符合、暂无法判断；点击股票先看实际数值与具体原因，再按需展开公式、报告期、采集时点、原始响应和独立来源核验。
4. 修改条件后旧结果明确标记；执行后查看新增/移出影响。选择 2–4 只比较，保存条件、导出证据或建立监控。
5. iFinD 提供财报原文核验和独立交叉检索；空结果及单位差异显式提示，不能替代本产品确定性筛选。

默认“经营改善、估值合理、走势相对稳定”映射为四项可修改假设：营收同比≥0%、归母净利润同比≥0%、市盈率TTM≤25倍、60日年化波动率≤30%。利润增速提升仅在明确要求或高级编辑时加入。条件修改后需重新执行，旧结果显式提示。保存、比较、导出及页面监控在结果之后呈现。

界面采用个人工具站的浅色、蓝色按钮、圆角卡片与顶部标签风格；本轮更新仍是独立演示站，尚未迁移到个人主站。后续路径、登录及服务器接入说明见 [docs/PERSONAL-SITE.md](docs/PERSONAL-SITE.md)。

## 职责边界

DeepSeek 只翻译条件、解释假设，不生成名单或财务数字。输出经字段白名单、范围、运算符、冲突和明确阈值保留校验。失败回退本地规则并披露原因。

src/engine.js 确定性计算指标、执行全部启用条件的 AND、产生入选/排除/未知证据及条件变化影响。金融工具只取真实字段和原文；扶摇优先，未配置时使用东方财富公开接口。接口失败对应数据转未知，不把旧值伪装成正常新结果。

## 数据与统计口径

文档：[扶摇](https://fuyao.aicubes.cn/docs/)、[iFinD MCP](https://mcp.51ifind.com/)。公开基线为东方财富，原始 URL、参数、采集时间与返回字段随 snapshot 保存。基线研究截止日 2026-10-09、采集日 2026-10-10；刷新以实际返回为准。

人工选择 24 只 A 股研究样本，不代表全市场或指数成分；行业为人工标签。合并报表累计营业总收入、归母净利润同比=(本期/上年同期−1)×100，基期非正为未知。增速改善=最新累计同比−上个累计同比，单位百分点，不等价于单季度经营改善。TTM=上年全年+本年累计−上年同期累计。

PE 优先采用扶摇 peTTM，公开基线用总市值/归母净利润 TTM；非正利润不作正常 PE。波动为 61 个后复权收盘价产生的 60 个对数收益率样本标准差×√252×100；回撤为同窗口峰谷损失。行情超过 7 个自然日、财报超过 200 天、估值时间缺失或落后、行情与历史日期不一致均进入待核验。这些是产品保守规则，不代表行业统一标准。

扶摇快照就绪时间不是交易日期；适配器使用同源最新日 K 线日期作为研究截止日，证据中说明依据。iFinD 可能返回“亿”而非请求的“元”，保留原文和口径提醒，不未经对齐声明一致。

## 边界和未做事项

仅支持 AND、有限指标和固定样本。没有全市场扫描、OR、行业估值分位、单季度经营拐点、交易执行、真正历史回测。历史财报版本和修订无法保证点时可用，因此未伪造无未来信息回测。

筛选和监控保存在当前浏览器，清除数据会丢失；监控只在页面打开且可见时轮询，关闭页面停止。没有后台推送、跨设备同步。授权数据不进入公共源码；用户导出仅限自己获准的用途。演示按所有者最新要求保持私有。目前未实现持久化调用预算和后台监控。

# 接入 goldsm.site 的准备说明

本轮仅更新独立私有演示站，未修改或发布个人网站。界面沿用个人工具的浅色背景、白色圆角卡片、蓝色按钮和顶部标签。后续建议作为“智能选股”加入工具列表，使用 `/tools/stock` 路径。

个人站当前为 Vue 前端与 Express 后端；本工具为独立 HTML 模块前端及可移植的 Request/Response 处理器。可以先通过同源反向代理接入，之后再按需要将界面拆成 Vue 页面：

1. 在主站工具列表和路由添加入口，由主站提供导航和登录；独立工具标题栏在共用导航时移除，避免重复。
2. 前端资源与请求采用相对路径；发布在 `/tools/stock/` 时，JS请求为 `/tools/stock/api/...`。代理层需要去除该前缀后交给本工具当前的根路径处理器，并保证真实外部 origin 一致，以保留跨站请求校验。
3. 用服务器秘密变量配置 DeepSeek、扶摇和 iFinD，前端只读取已配置状态。不要把密钥放在 Vue 构建变量或公开配置中。
4. 主站登录需要保护金融 API；明确谁可访问及配额策略后再公开。演示站的私有权限只保护演示域名，不自动保护个人站。
5. 当前浏览器保存的条件按域名隔离，迁移后不会自动带过去；可导出条件后再按需做导入或账户同步。授权原始响应不应写入主站公开缓存。

本轮未实现主站路由、登录接入、账户同步、配额控制或个人站生产部署。这些应在确认最终接入方式后单独完成。

## 主链路

新增四项步骤状态测试：首次不能进入结果、整理后仍需确认、修改原句必须重整且旧结果保留标记、阈值草案经执行才解除旧结果标记。

覆盖意图解析、明确阈值、澄清、字段和运算符、冲突检查；同比与 TTM 独立核算、60 日波动独立公式验证；AND 筛选、未知优先、收紧条件的集合单调性、新增/移出影响及真实公开快照复现。

新版默认四项条件在公开快照固定研究时点下为12符合、11未符合、1暂无法判断。PE 上限25→15时，12→8，五粮液、长江电力、中国神华和中国石化移出。高级增速条件重新启用后恢复旧版9只；旧版9→7记录仍对应五项条件。

新版浏览器现场完成真实 AI 四条件草案、确认执行、扶摇刷新、条件变化预览与应用、排除依据、两只公司比较、保存与载入。初始页面没有未经确认的候选；高级编辑默认折叠；修改后旧结果提示且禁止保存；问号点击和键盘聚焦均显示说明，Escape关闭。悬停通过同一提示组件绑定 pointerover/pointerout；未用鼠标移动工具单独自动验证该事件。桌面与手机布局检查见 UI-VALIDATION.md。

## 数据/接口异常

覆盖负或零同比基期、非正 TTM、缺失字段、研究时点后的公告、行情/财报过期、估值时间缺失、历史与行情日期冲突。HTTP 429、网络失败、无效 JSON、模型失败或非法输出明确报错/回退。

覆盖非法刷新批次、跨站 POST、过大请求体、未知接口和 CSP。iFinD 空列表不代表确定不存在匹配股票，口径未对齐不宣称一致。

## 极端和合规边界

覆盖重复 ID、越界阈值、上下限冲突、过多条件、AI 幻觉字段、遗漏明确阈值、未配置授权。收益承诺、确定性涨跌预测和直接交易请求在调用模型前拦截。配置接口与静态路由不暴露密钥，授权数据构建防护。

首版真实调用摘要见 LIVE-VALIDATION.json，新版复核见 AI-USE.md 和 UI-VALIDATION.md；故障测试使用替身。当前演示私有，未完成评委匿名访问、全市场压力测试、长时间后台监控及全面渗透测试。

## 2026-10-11 解析与预制方案补充回归

解析专项新增 11 项测试：

- 只指定行业、仅要求未支持指标时，合法空条件进入 llm 澄清状态；仍需补充指标，执行引擎返回“至少启用一条条件”。
- 纯数字字符串转换后保留原阈值和严格运算符，并产生转换记录与用户核对说明；带单位、空串、布尔值、指数等字符串拒绝自动转换。
- 未知字段、非法比较方式、越界阈值分别产生具体诊断和失败请求 ID；原型属性不能绕过字段或运算符白名单。
- 结构不完整、null 条件和超过 20 条条件分别诊断；合法上下限冲突保留给用户修改。
- AI 改动明确阈值或严格比较方式时回退，原表达继续保留。
- HTTP 429、无条件内容、非 JSON 内容、响应读取失败、网络异常与超时分别提示；异常内容中的模拟凭据不得出现在返回结果。

新增 4 项预制方案测试覆盖：四个模板标识唯一且条件可执行；默认条件、阈值、单位和行业符合模板定义；反复载入、编辑与保存不会污染模板或其他草稿；未知模板标识不静默载入替代方案。模板不保存股票名单或候选数量，载入后仍需用户确认再执行。

真实 DeepSeek 请求验证了旧代码对“银行行业”和“ROE至少10%”的空条件误报，修复后均进入澄清；标准四项意图继续正常解析。旧、新请求 ID 及验证限制见 AI-USE.md 的同日记录。用户未提供报错原句，因此这些检查不能认定其唯一触发原因。数字字符串、非法输出及接口失败使用替身验证；本节不作新增浏览器操作或本轮构建通过的结论。
